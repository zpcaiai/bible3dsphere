# 人物卡片 ID 201–277

## ID 201 亚拿女先知 (Anna the Prophetess)
**时代：** 新约时代 | **角色：** 女性 | **类型：** 正面
**功课：** 一生等候神应许的忠心
**摘要：** 八十四岁的女先知，守寡后在圣殿昼夜祷告禁食，在圣婴耶稣被带来圣殿时立即认出，向众人宣告。
**见证：** 她守寡多年，没有离开圣殿，昼夜禁食祷告事奉神。七十年的等候。然后在八十四岁那年，她等候的终于出现了——她亲眼看见婴儿耶稣，立刻感谢神，向众人讲论这孩子。漫长的等候不是浪费，而是积累。
**效法：** 以整个生命的持续事奉等候神的时机；在见到神的应验时立刻感谢并向众人宣告
**警戒：** —
**应用：** 你在等候神什么？你的等候方式是积极的事奉还是消极的等待？；七十年的事奉换来一刻的见证——值得吗？；今天在你的等候中，主动地事奉
**祷告：** 主，亚拿等候了七十年，在圣殿昼夜事奉，然后看见了你。帮助我在等候中不荒废，而是用等候的时间昼夜事奉你。阿们。

## ID 202 西面（圣殿老人） (Simeon)
**时代：** 新约时代 | **角色：** 其他 | **类型：** 正面
**功课：** 等候神应许直到亲眼看见
**摘要：** 公义虔诚的老人，圣灵启示他未死之前必能看见主的基督，婴儿耶稣被带来时他抱着他说：我可以安然去世了。
**见证：** 他不知道要等多久，但他知道神的应许必然成就。当那一天来到，他抱着婴儿耶稣说：主啊，如今可以照你的话，释放仆人安然去世了。等候的终点是满足。他等了一生，只为这一刻，然后说：够了，我可以去了。
**效法：** 以圣灵的引导等候神具体的应许；在应许成就时以感谢和满足结束等候
**警戒：** —
**应用：** 你有神给你的特别应许吗？你在等候中吗？；等候不是无所事事，而是以信心活在当下；当神应许成就那天，你会说什么？
**祷告：** 主，西面等候了你的应许，然后说：够了，我可以安然去世了。帮助我在等候中有同样的信心，知道你的应许必然成就。阿们。

## ID 203 亚哈随鲁王 (Ahasuerus)
**时代：** 被掳归回时代 | **角色：** 君王 | **类型：** 混合
**功课：** 权力在神手中被翻转
**摘要：** 波斯王，以斯帖记的背景君王，起初轻率废后，被哈曼操控，最终在以斯帖的智慧和神的主权下，成为拯救犹太人的工具。
**见证：** 他是大帝王，但他的决定几乎都是被别人影响的——先被哈曼操控，后被以斯帖的智慧改变。圣经对他没有明显的属灵评价，但他的每个关键决定都在神的主权下服务于神的计划。神能使用任何人——即使那人不知道自己被使用。
**效法：** 在以斯帖的正确引导下做出正义的决定
**警戒：** 轻率地被身边的人操控做出不当决定；权力而没有智慧的引导是危险的
**应用：** 你周围有没有像以斯帖那样的智慧声音？你是否听从？；神能使用任何人的决定来成就祂的计划；你的权力是否在正确引导下使用？
**祷告：** 主，你在亚哈随鲁王的决定中掌权，即使他不认识你。谢谢你的主权超越人的权力。帮助我成为传递你智慧的声音，而非操控的力量。阿们。

## ID 204 以利户 (Elihu)
**时代：** 族长时代 | **角色：** 其他 | **类型：** 混合
**功课：** 年轻的热情与有限的洞察
**摘要：** 约伯三友之后出现的年轻人，因不满三位老友无法回答约伯而发怒，用大量言辞为神辩护，最终被神绕过而不评论。
**见证：** 他等了很久才开口，因为年轻而等候年长者先说。他的出发点是对神的热情——他真诚地想为神辩护。但他的话很多，神最后只提了约伯和三位朋友，没有提到他。热情而没有谦卑，言辞多而不到位。年轻的热心需要时间和苦难来深化。
**效法：** 等候年长者先说话的谦卑；对神的真诚热情是好的出发点
**警戒：** 说很多话却没有真正帮助到受苦者；以热情代替了真实的倾听和同理
**应用：** 你说话的时候，是在解释还是在真正帮助？；热情是好的起点，但不是终点；今天少说一句，多听一句
**祷告：** 主，以利户热情却被你绕过。帮助我的热情不只是多说，而是真正地倾听、真正地同理，说出你真正要说的话。阿们。

## ID 205 撒母耳 (Samuel)
**时代：** 士师时代 | **角色：** 先知 | **类型：** 正面
**功课：** 从小听见神声音到终生忠心事奉
**摘要：** 由哈拿许愿归还给神的孩子，在圣殿由以利抚养，幼年便听见神的呼唤，成为以色列最后一位士师和最伟大的先知之一。
**见证：** 神三次呼唤撒母耳，他以为是以利在叫他，三次去问以利。以利终于明白是神在说话，教他说：请说，你仆人敬听。然后神的话来到了。人生最重要的装备，是学会分辨神的声音。他终生保持了这种聆听。撒上12:3：我在这里，你们可以在耶和华和祂的受膏者面前控告我。这是终生清白的宣告。
**效法：** 从小培养聆听神声音的敏感度；终生保持清廉和忠心，可以在人面前宣告清白；在百姓要求不合神意之事时仍然说真话
**警戒：** —
**应用：** 你能分辨神的声音吗？你用什么来辨别？；终生的清白是每一天的选择积累；今天学撒母耳说：请说，你仆人敬听
**祷告：** 主，撒母耳从幼年就学会说：请说，你仆人敬听。帮助我今天也以这样的姿态来到你面前，安静地等候你的声音。阿们。

## ID 206 利亚 (Leah)
**时代：** 族长时代 | **角色：** 女性 | **类型：** 混合
**功课：** 在不被爱中寻求神
**摘要：** 雅各不爱的妻子，却接连为他生儿子，圣经描述她的每次生产都是她与神的对话，最终被葬在亚伯拉罕家族的墓地。
**见证：** 她生第一个儿子说：耶和华看见了我的苦情。生第三个儿子说：这次我要赞美耶和华。她把痛苦转化为对神的倾诉，在雅各的冷落中，神一直在看见她。被人忽视不等于被神遗忘——神垂顾那些被人边缘化的人。
**效法：** 在不被爱的处境中转向神；用生命的每个经历与神对话
**警戒：** 与姊妹的嫉妒竞争拖累了家庭关系
**应用：** 你在某段关系中是否感到不被重视？神也看见你；把痛苦转化为祷告而非苦毒；「这次我要赞美耶和华」——在痛苦中找感恩的理由
**祷告：** 主，利亚在不被爱中仍然转向你。帮助我在被忽视时记得你的眼睛永远看见我，把每一次痛苦都变成向你倾诉的机会。阿们。

## ID 207 拉结 (Rachel)
**时代：** 族长时代 | **角色：** 女性 | **类型：** 混合
**功课：** 深爱与不育之痛的挣扎
**摘要：** 雅各深爱的妻子，长期不育，终于生下约瑟，在生便雅悯时难产而死，成为以色列民族情感中最深的母亲形象。
**见证：** 她的眼泪和等候是真实的。神终于垂听她开了她的胎，她生了约瑟。但她没有满足，她继续渴望，最终在生第二个儿子时离世。先知耶利米引用她的哭声来描述以色列被掳的悲痛：拉结哭她的儿女，不肯受安慰。她的形象成了代代母亲之爱的象征。
**效法：** 深情地爱，真实地等候神；在得到所求之后仍然信靠前行
**警戒：** 嫉妒姊妹，说：你若不给我儿子，我就死了；偷走父亲的神像，带来麻烦
**应用：** 你有没有像拉结那样迫切渴望的事？把它带到神面前；深爱是神的礼物，但不能成为偶像；即使在等候中，神记念了她
**祷告：** 主，拉结的等候和眼泪你都看见。帮助我把最深的渴望诚实地带到你面前，在等候中信靠你的时间，而非用嫉妒和抓取代替等候。阿们。

## ID 208 书念妇人 (Shunammite Woman)
**时代：** 王国时代 | **角色：** 女性 | **类型：** 正面
**功课：** 慷慨款待与坚定的信心
**摘要：** 一位富有的书念妇人，主动为以利沙建了一间客房，儿子死后独自去找先知，不轻易接受安慰，只要先知亲自去，结果儿子复活。
**见证：** 儿子死了，她把他放在床上，对丈夫说：平安无事。然后骑驴去找先知，一路不停。当以利沙的仆人问：你好吗？她说：平安。她没有在路上崩溃，她一路保持，直到见到先知，才在他脚前哭泣。信心不是否认痛苦，而是知道去哪里找答案。
**效法：** 主动慷慨款待神的仆人，不等被要求；在危机中直奔有能力的人面前，不走弯路
**警戒：** —
**应用：** 你有没有「给先知建客房」的慷慨？主动为神的工作提供；信心是知道去哪里——今天你有危机时去哪里？；「平安」不是谎言，是对神掌权的信心宣告
**祷告：** 主，书念妇人为你的仆人建了客房，在危机中直奔你面前。帮助我有同样慷慨的心，在危机中也知道直接来到你面前。阿们。

## ID 209 拔示巴 (Bathsheba)

**功课：** 从悲剧到王后的蜕变
**摘要：** 被大卫强取的妇人，丈夫乌利亚死后成为大卫的妻子，第一个孩子死去，后来生所罗门，最终成为为儿子争取王位的母亲。
**见证：** 她是故事里最无辜的受害者——被权力强取。第一个孩子死了，是大卫罪的代价。然后她生了所罗门。在大卫晚年，她智慧地确保所罗门登基，成为母后。悲剧的入口不是结局。神在她破碎的故事里继续工作，所罗门成了最有智慧的王。

**应用：** 你生命里最大的悲剧是终点还是神继续工作的地方？；拔示巴的故事：神能在他人的罪行造成的伤害中仍然工作；今天选择前进，而非停留在伤害的故事里
**祷告：** 主，拔示巴的故事是悲剧，但你在其中仍然工作。谢谢你不因别人对我的伤害而放弃我。帮助我也在最破碎的地方看见你继续工作。阿们。

## ID 210 撒罗米 (Salome)

**功课：** 陪伴十字架与复活的女门徒
**摘要：** 西庇太的妻子、雅各和约翰的母亲，曾为儿子求高位，却也是站在十字架旁、第一批来到空坟墓的女人之一。
**见证：** 她曾求耶稣让两个儿子坐在祂左右。耶稣说：你们不知道你们所求的是什么。然后十字架上，她站在那里。她看着儿子的师傅被钉死，仍然留下来。然后成为第一批复活见证人。从求高位到站在十字架下——这是真实的门徒成长。
**效法：** 从追求高位成长为愿意站在十字架下的门徒；成为复活的早期见证人
**警戒：** 为儿子谋求高位，超越神的拣选次序
**应用：** 你是否也曾为自己或家人求高位？如何回应耶稣的「你不知道所求的」；门徒成熟的标志：从追求地位到愿意同受苦难；今天在十字架下站立——在苦难中不离开耶稣
**祷告：** 主，撒罗米从求高位到站在十字架下。帮助我也从追求地位成长为愿意陪伴你走苦难的路，直到看见复活。阿们。

## ID 211 以利沙伯 (Elizabeth)

**功课：** 在老年仍然蒙神垂听的等候

**应用：** 你的等候是否已经让你「无可指摘」——忠心等候？；有时神的回答等到老年才来，但一定来；今天是否有机会像伊利沙白一样，为别人的信仰说一句祝福的话
**祷告：** 主，伊利沙白等候了一生，你在老年给她一个先知。帮助我在漫长的等候中仍然义人无可指摘，相信你的时候必然来到。阿们。

## ID 213 腓力 (Philip the Apostle)

**应用：** 你认识耶稣之后第一件事是去找谁？；今天你能去找谁说：我找到了？；腓力的问题是你的问题：神，让我更认识你
**祷告：** 主，腓力找到了你，立刻去找朋友分享。帮助我也有同样的反应——遇见你，就去找人。阿们。

## ID 214 巴多罗买 (Bartholomew)
**时代：** 新约时代 | **角色：** 使徒 | **类型：** 正面
**功课：** 没有诡诈的真以色列人
**摘要：** 即拿但业，被耶稣称赞为「真正的以色列人，心里没有诡诈」。起初质疑拿撒勒能出什么好的，被腓力说服来见耶稣后，立刻认定祂是神的儿子。
**见证：** 耶稣看见他来就说：看哪，这是个真以色列人，他心里没有诡诈。拿但业问：你怎么认识我？耶稣说我看见你在无花果树底下。这一句话足够了。没有诡诈的心，配得上神完全的知道。他被完全知道，因此也完全信任。
**效法：** 心里没有诡诈，是信仰最基本的品格；愿意被朋友说服来亲自验证
**警戒：** 初期有地域偏见：拿撒勒能出什么好的
**应用：** 你是否愿意在神面前「没有诡诈」——诚实展示你真实的状态？；偏见阻止我们遇见神，今天放下一个偏见；被完全知道却仍被爱：这就是福音
**祷告：** 主，你看见拿但业在无花果树底下。你也看见我一切隐藏的地方。帮助我像他一样，被完全知道，仍然完全信任你。阿们。

## ID 215 马太 (Matthew)
**时代：** 新约时代 | **角色：** 使徒 | **类型：** 正面

**时代：** 新约时代 | **角色：** 主&救主 | **类型：** 正面
**功课：** 祂是圣经六十六卷的核心与终点——旧约所有人物都是祂的影子，新约揭示祂的真身。祂道成肉身，完全认同人的软弱；在客西马尼俯伏祷告，完全顺服父的旨意；在十字架上承担全人类的罪；在复活中宣告死亡已被征服。祂不只是最好的榜样，祂是我们得以效法任何榜样的力量来源。
**摘要：** 耶稣基督，神的永恒之子，在创世之先已存在（约1:1），在时间的中心成为肉身（约1:14），藉马利亚生于伯利恒（路2:7），在拿撒勒成长（路2:51-52），约三十岁开始传道，在加利利、撒玛利亚和犹大宣扬天国福音、医治病人、赶鬼、使死人复活。祂召聚十二门徒，以比喻和登山宝训教导神国的生活方式。在逾越节前夕，祂设立圣餐（太26:26-28），在客西马尼园流血汗祷告（路22:44），被犹大出卖，经彼拉多审判，在各各他十字架上受死（约19:30），第三天复活（路24:6），四十天后升天（徒1:9），将来必再来审判活人死人（启22:20）。祂的生命囊括了所有人类处境：贫穷、拒绝、孤独、误解、背叛、苦难、死亡——祂都亲身经历，因此祂是完全能体恤我们的大祭司（来4:15-16）。
**见证：** 圣经每一位人物的功课，都在祂身上找到完全的原型与成就：
亚当失去的，祂作为末后的亚当来恢复（林前15:45）；
挪亚造方舟拯救人，祂以十字架拯救全人类；
亚伯拉罕愿意献以撒，祂是那真正被献的独生子（约3:16）；
约瑟被兄弟出卖却成为救恩的管道，祂被门徒出卖却成为世界的救主；
摩西是中保和代求者，祂是唯一的中保（提前2:5）；
大卫是按神心意的牧羊王，祂是好牧人（约10:11），是大卫更伟大的子孙（太22:42-45）；
以利亚在旷野中疲惫，天使来喂养，祂在旷野四十天禁食受试探，却胜过了每一个试探；
约伯在苦难中质问神，祂在十字架上喊出「我的神，我的神，为何离弃我」（诗22:1，太27:46）——这是祂真实承担了人类被遗弃感的记号；
路得说「你往哪里去，我也往那里去」，祂道成肉身进入人类的处境，比路得更彻底地委身；
约拿在鱼腹三天，预表祂在地里三天（太12:40）；
以赛亚53章所描绘的受苦仆人，就是祂——「他为我们的过犯受害，为我们的罪孽压伤」。祂不是圣经众人物之一，祂是所有人物指向的那一位。
**效法：** 道成肉身：完全进入人类处境，不从远处怜悯，而是亲身经历软弱、贫穷、拒绝（约1:14，腓2:7-8）；完全顺服：在客西马尼说「不要照我的意思，只要照你的意思」，是人类历史上最深刻的顺服（路22:42）；十字架之爱：在被钉时说「父啊，赦免他们，因为他们所做的他们不晓得」——祂在受苦中仍然代求（路23:34）；复活：死亡不能留住祂，这是对每一个在苦难中绝望的人的终极答案（路24:6，林前15:54-57）；恢复失败者：复活后第一件事之一是特别恢复三次否认祂的彼得（约21:15-17），这是祂对失败者的态度；接纳被弃绝者：税吏撒该、行淫被拿的妇人、撒玛利亚妇人、十字架上的强盗——祂专门寻找社会边缘人（路19:10）；真实的情感：祂在拉撒路墓前哭泣（约11:35），在耶路撒冷上叹息（路19:41），为人类的苦难真实动情；最后的话语：「成了」（约19:30）——这是宣告，不是叹息；救赎计划完全成就
**警戒：** —
**应用：** 你现在面对的苦难、拒绝、失败，祂都亲身经历过——来4:15说祂『与我们一样，曾经凡事受过试探』，你不是在独自面对；效法圣经里任何一位人物，最终目标是更认识祂。约瑟的宽恕、大卫的悔改、路得的委身——这些美德在祂身上都是完全的；当你感到被神遗弃，记住祂也喊出了『我的神，我的神，为何离弃我』——祂走过了你所在的黑暗，并且从那里走出来了；「效法基督」不是靠意志力模仿一个遥远的榜样，而是靠住在祂里面（约15:5）——藤与枝的关系，不是学生与老师的关系；你在镜鉴中看到的每一个人物，都是在说：『有一位比我更好的正在来』——祂来了，祂就是耶稣
**祷告：** 主耶稣，你是圣经的核心，是一切人物的终点，是我们所有功课的完全示范。感谢你道成肉身，进入我们最真实的处境；感谢你在客西马尼的祷告，告诉我们顺服的样式；感谢你在十字架上说『父啊，赦免他们』，让我们知道爱可以在最深的痛苦中仍然给出；感谢你复活，让我们知道最黑暗的死亡不是终点。帮助我不只是仰慕你，更是住在你里面，让你的生命从我里面流出，而不是我努力模仿你在外面。你是主，你是救主，也是我今天最真实的同行者。阿们。

## ID 275 友阿爹 (Euodia)
**时代：** 新约时代 | **角色：** 其他 | **类型：** 警戒
**功课：** 同工之间的不和会伤害教会的见证
**摘要：** 腓立比教会的女信徒，曾与保罗一同为福音劳苦，却与同工循都基发生争执，保罗在书信中点名请她们在主里和好，成为教会历史上最著名的同工冲突案例。
**见证：** 保罗没有回避这个冲突，而是在公开书信中点名劝和。能被保罗点名「曾与我一同为福音劳苦」，说明她真实地服事过；但争执成了见证的绊脚石。同工的不和不是小事，它会让世界误解福音。
**效法：** 曾真实地与保罗同工为福音劳苦
**警戒：** 与同工循都基发生争执，影响教会见证；使保罗需要公开书信劝和
**应用：** 教会中你是否有需要和好的关系？今天迈出第一步；同工之间的争执比外来的逼迫更伤害教会，不要让私人矛盾成为福音的拦阻
**祷告：** 主，保护我与同工的关系，使我在基督里和好，让我们的一致成为福音的见证。阿们。

## ID 276 循都基 (Syntyche)
**时代：** 新约时代 | **角色：** 其他 | **类型：** 警戒
**功课：** 曾经的同工因争执需要在主里和好
**摘要：** 腓立比教会的女信徒，曾与保罗一同为福音劳苦，却与同工友阿爹发生争执，保罗在腓立比书中点名劝她们在主里和好，是新约中关于教会同工冲突的经典案例。
**见证：** 她和友阿爹都是真实服事过的人，但争执让她们需要保罗公开调解。有时越是热心服事的人，越容易在同工关系上发生摩擦——因为都在乎，所以都有主见。保罗说「在主里」和好，提醒她们和好的基础不是谁对谁错，而是共同在主里的身份。
**效法：** 曾真实地与保罗同工为福音劳苦
**警戒：** 与同工友阿爹争执，需要保罗公开劝和
**应用：** 和好的基础是「在主里」，不是谁让步谁赢了；你现在有没有与某位同工的关系需要修复？
**祷告：** 主，让我在与同工的冲突中先看自己的部分，以基督里共同的身份为基础和好。阿们。

## ID 277 乃缦的小女仆 (Naaman's Servant Girl)
**时代：** 王国时代 | **角色：** 其他 | **类型：** 正面
**功课：** 一个被掳小女孩的一句话改变了一位大将军
**摘要：** 以色列被掳的小女孩，在叙利亚大将乃缦家中作女仆，得知主人患麻风，主动告诉主母有关以利沙先知能医治的消息，最终导致乃缦得医治、认识以色列的神，是圣经中以小见大的最感人案例之一。
**见证：** 她是战争的受害者——被掳、为奴、异乡。她有充分的理由沉默，甚至袖手旁观。但她没有。她说：巴不得我主人去见撒马利亚的先知。一句话，从一个没有名字的女孩口中，启动了乃缦整个生命的转折。神有时用最小的人说出最重要的话。
**效法：** 在异乡处境中没有苦毒，仍然关心主人的处境；主动见证神的能力，即使自己是奴仆
**警戒：** —
**应用：** 你在你的处境中是否有「一句话」可以说出，引人归向神？；即使你感到渺小、被忽视，神仍然可以使用你的一句话
**祷告：** 主，乃缦的小女仆提醒我：你不需要我有地位、有名字，只需要我愿意开口。帮助我在日常的处境中，不让机会白白溜过。阿们。
