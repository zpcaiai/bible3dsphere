# 人物卡片 ID 121–200

## ID 121 亚撒 (Asa)
**时代：** 王国时代 | **角色：** 君王 | **类型：** 混合
**功课：** 初期改革后期依靠人
**摘要：** 犹大好王，初期除去偶像、依靠神得胜，晚年却依靠外邦王大亚蒙，不再信靠神。
**见证：** 亚撒的一生是双阶段的对比：前期的改革热情与后期的依靠人形成鲜明对比。他的故事警告我们：属灵热情需要终身维持，而不只是开始。
**效法：** 初期积极除偶像恢复敬拜；在危机中先求问神
**警戒：** 晚年在威胁面前依靠外邦王而非神；先知指责他时恼怒迫害先知
**应用：** 检视：我的信仰热情是否随年日递减？；在每次危机中先祷告再寻求人的帮助
**祷告：** 主，亚撒的晚年提醒我：信仰不能靠老本。帮助我每天更新对你的依靠，不让成功或年岁使我离开你。阿们。

## ID 123 约坦 (Jotham)
**时代：** 王国时代 | **角色：** 君王 | **类型：** 正面
**功课：** 安静忠心的正直领导
**摘要：** 犹大王，行正直，日渐强盛，是安静忠心领导的典范。
**见证：** 约坦没有戏剧性的危机或失败，只是稳定地行在神面前，日渐强盛。忠心有时不是戏剧性的，而是安静、持续的。
**效法：** 行正直心志坚定；不因父亲乌西雅的失败而放弃信仰
**警戒：** —
**应用：** 安静忠心地做好手头的事积累长期影响力；检视：我是否在无人注意时仍然做正确的事？
**祷告：** 主，约坦的生命告诉我：忠心不一定需要大事件。帮助我在平凡日子里安静地行在你面前，日渐强盛。阿们。

**祷告：** 主，亚哈斯拒绝你的帮助。帮助我在最大的压力下转向你而非转向人。阿们。

## ID 125 玛拿西 (Manasseh)
**时代：** 王国时代 | **角色：** 君王 | **类型：** 混合
**功课：** 极深的罪与极大的悔改
**摘要：** 犹大历史上最恶的王，但在极刑下真心悔改，神恢复了他，是悔改永不嫌迟的见证。
**见证：** 他做了最恶的事，被俘到巴比伦在极刑中极其谦卑地呼求神。神垂听了。这是圣经最惊人的悔改故事之一。
**效法：** 在极苦难中真心悔改；悔改后立即行动除去偶像恢复敬拜
**警戒：** 早期极端的偶像崇拜和罪恶；影响了整代人的属灵败坏
**应用：** 没有人堕落得太深以至于神不能恢复；今天有什么是你以为神不能饶恕你的？
**祷告：** 主，玛拿西的悔改告诉我：不管我走了多远，你的手仍然可以够到我。谢谢你不放弃最深的罪人。阿们。

## ID 136 哈巴谷 (Habakkuk)

**祷告：** 主，哈巴谷带着所有的疑问仍然说：我要靠神喜乐。帮助我在最看不见你的时候，仍然选择喜乐。阿们。

## ID 141 沙得拉、米煞、亚伯尼歌 (Shadrach, Meshach, Abednego)

**祷告：** 主，三位少年说：即便祂不救，我们也不跪拜。帮助我的信仰不以你的拯救为条件，因你是神就愿意顺服。阿们。

## ID 143 亚比该 (Abigail)
**时代：** 王国时代 | **角色：** 女性 | **类型：** 正面
**功课：** 智慧与调解化解冲突
**摘要：** 拿八的妻子，在丈夫因愚顽激怒大卫时，凭着智慧和主动出面阻止了大卫的报复，后来成为大卫的妻子。
**见证：** 亚比该的智慧不只是聪明，而是以神的视角看问题。她说：不要让大卫因报复而玷污自己的良心。她同时保护了大卫、丈夫，和她的家。真正的智慧是三赢的。
**效法：** 主动在危机中出面不躲避；言辞谦卑而内容有力

**应用：** 你有没有建立自己的「金牛犊」——用方便的替代品代替真正的敬拜？；政治考量常常是顺服神最大的障碍；检视：决策时神的旨意是第一位还是我的利益是第一位？
**祷告：** 主，耶罗波安用政治考量代替了对你的顺服。帮助我在决策中不以方便和稳定作为第一考量，而是真正地寻求你的旨意。阿们。
