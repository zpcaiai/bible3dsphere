# Privacy, Consent, and Relational Safety Evaluation

Required cases cover purpose limitation, withdrawn consent, deletion propagation, tenant isolation, minimized logs, notification leakage, untrusted relationship sharing, profiling objection, and unauthorized evaluation reuse.

Batch 8 relational collaboration is absent in this checkout. Relational sharing and any release gate that depends on it therefore fail closed; Batch 10 does not emulate or silently replace it. Privacy tests validate code contracts, while live RLS, role permissions, and deletion propagation require database-backed integration evidence.
