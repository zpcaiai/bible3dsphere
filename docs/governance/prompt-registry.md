# Prompt Registry

Every production prompt has an immutable ID and version, owner, intended task, input/output contract, allowed tools, prohibited behavior, linked evaluation report, and approval state. `latest` aliases and unreviewed prompt text are release blockers.

Prompt templates must treat journals, retrieved documents, tool output, and user content as untrusted data. They cannot weaken consent, tenant, crisis, deletion, or divine-authority boundaries. Prompt changes run theological, crisis, privacy, injection, and task-specific suites before activation.
