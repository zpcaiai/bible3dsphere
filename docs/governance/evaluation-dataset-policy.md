# Evaluation Dataset Policy

Permitted sources are synthetic, expert-authored, consented user donation, and licensed public material. Every dataset must record version, provenance, intended task, language, consent basis, retention class, sensitivity, and exclusions.

Production user content is excluded by default. Consent for product use does not imply consent for evaluation or training. Revoked/deleted content must be removed from cases, caches, embeddings, search, shadow outputs, and derived datasets; deletion tombstones survive restore.

High-risk datasets require privacy and domain review. Synthetic results are labelled synthetic and may not be presented as production effectiveness evidence.
