# Compliance Center

## User-Facing Commitments

The Formation Twin compliance surface must show what data is processed, why it is processed, which processors are involved, and what rights the user can exercise.

## Required Controls

- Data map by purpose, source, retention class, and sensitivity.
- Third-party processor register with region, purpose, and DPA status.
- Rights request intake for access, export, correction, deletion, restriction, and objection.
- Profiling explanation for non-automated inferences, including uncertainty and user correction.
- Plain-language disclosure that the system is not a therapist, pastor, physician, or oracle.

## Launch Boundary

The implementation provides API/UI surfaces and database tables. Real production compliance still requires legal review, processor contracts, configured retention jobs, and verified deletion/export workflows.
