# Third-Party Processor Governance

## Required Register Fields

- Processor name.
- Purpose.
- Data categories.
- Region.
- Subprocessor status.
- DPA or contract status.
- Retention and deletion support.
- Security review owner.

## Rules

No processor may receive Formation Twin sensitive data unless purpose, consent, data minimization, transfer basis, retention, and deletion support are documented.

## Current Boundary

Batch 10 adds processor registry APIs and database tables. It does not substitute for vendor legal review, DPA execution, or security questionnaires.
