# Reflection and Intervention Safety

Every mirror, question, proposal and routing payload is checked before display
or dispatch. High-severity findings fail closed.

The validator blocks divine-oracle claims, salvation or repentance judgments,
psychological or medical diagnosis, shame and fear persuasion, capacity
overload, hidden reminders, multiple actions, automatic third-party sharing and
sensitive routing payloads. It also blocks spiritual and compliance scores.

Degradation is: smaller action, question only, mirror only, store only, then
Crisis Care. ELEVATED and IMMINENT safety states never pass an ordinary action.
Blocked text is not copied into ordinary logs or event payloads.

The engagement guard separately blocks streak pressure, badges, ranks,
leaderboards, failure penalties and anxiety-based re-engagement.
