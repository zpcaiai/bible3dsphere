# Passive Signal Boundaries

Passive risk metadata is off by default and uses a consent distinct from normal
Formation Twin processing. Allowed inputs are bounded metadata such as a user-
defined time window, self-reported sleep, Attention screen-time summary, active
boundary state, user-selected environment tag or support availability.

Raw browser/search/message content, keystrokes, camera, microphone, photos,
precise location, contact interaction, transaction content and private app
content are prohibited even when a caller labels them metadata. Raw content also
fails closed.

Local processing is preferred: upload a boolean/summary rather than source
activity. Settings must disclose the signal, purpose, retention and disable /
delete path. Disabling consent stops new processing and the scoped erase removes
stored conditions and derivatives.
