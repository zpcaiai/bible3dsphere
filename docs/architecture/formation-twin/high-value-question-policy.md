# High-Value Question Policy

The selector shows one question. Safety, present user report, an unanswered
gap, a confirmed choice point, an alternative response, protection and grace
are ordered ahead of future action planning.

Very-low and low capacity prefer rest, emotion naming and human connection.
Unconfirmed patterns may only produce a clearly framed clarification question.
The selector records rationale, source reference, burden level and template
version.

The same question type is cooled down for seven days. “Do not ask this again”
creates a long cooldown and the system must not immediately ask a synonym.
Questions about alleged idols, false repentance, divine punishment or whether
the user “really believes” are prohibited.

Selection utility is internal, local to the user and never becomes a readiness,
obedience or compliance score.
