# Formation Trajectories

A trajectory describes direction over time without producing a growth total.
Supported directions are EMERGING, STRENGTHENING, STABLE, WEAKENING,
BEING_REPLACED, DORMANT, RESOLVED_BY_USER, MIXED, and INSUFFICIENT_DATA.

The engine creates or refreshes a trajectory when the user confirms a pattern,
marks it weakening/dormant/resolved, or supplies counterevidence. Points retain a
time window, direction, source pattern IDs, counterevidence references, evidence
quality, and limitations. They do not copy sensitive descriptions.

Old and alternative responses can coexist. Counterexamples, grace, protection,
recovery, relational support, rest, boundaries, honest disclosure, professional
support, and church support can all explain why a previous response did not
occur. The system presents those as recorded associations, not certain causes.

With insufficient evidence the UI renders an honest empty state instead of a
curve. A user correction supersedes the current trajectory direction and is not
treated as resistance.
