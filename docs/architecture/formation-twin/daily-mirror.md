# Daily Reflection Mirror

A daily mirror is generated on demand by default. Its visible shape is one
mirror, one question, and at most one proposed action. It is not an automatic
devotional coach.

The mirror uses source-bound language such as “you recorded” and “you previously
confirmed.” It does not use fixed-personality, hidden-motive, salvation, divine
oracle or diagnosis language. A protection, grace, recovery or alternative
response is included when available so the mirror is not only a problem list.

Normal mirrors are limited to about 150 Chinese characters; very-low-capacity
mirrors are limited to about 80. Every active mirror has source references and
limitations. User correction creates a new version and supersedes the previous
mirror instead of rewriting history.

Crisis ELEVATED or IMMINENT suppresses ordinary analysis and routes to the
existing Crisis Care entry. STORE_ONLY suppresses analysis completely.
