# Unified information architecture

The Vite React surface exposes ten user routes inside one responsive portal:

1. Home — state, short mirror, one question, at most one focus action.
2. Today — direct routes to check-in, prayer and devotion.
3. Twin — Formation Twin records, evidence and review.
4. Practices — Prayer, Devotion, Formation and Attention source modules.
5. Calling — Gift/Calling and Mission source modules.
6. Collaboration — user-selected human, mentor and church relationships.
7. Timeline — source-labelled metadata references; no copied body.
8. Search — current-user confirmed references; query not logged.
9. Actions — at most three active and one focus; non-moral statuses.
10. Privacy — projection consent and context-access audit.

Safety help is always present. When evidence is insufficient, Home says so and
offers check-in/module navigation. It does not synthesize a mirror for visual
completeness. Technical integration health is not shown to ordinary users.

The portal links back to source modules for editing and execution. Chinese-first
visible labels do not change backend enum or contract values.
