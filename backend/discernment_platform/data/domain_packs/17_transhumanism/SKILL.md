# 1. Purpose

识别、解释并牧养性分析“超人类主义”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 身体只是可替换硬件
- 增强者更有价值
- 数字复制等于永生

## Excludes / Do not overclassify
- 医疗治疗
- 残障辅助
- 合伦理的寿命研究

# 3. Fair Definition

把受造有限性和身体本身视为应被技术超越的缺陷，并以升级、数字永生或物种跃迁代替复活。

它通常把人的根本问题描述为：**身体脆弱、衰老、死亡和生物限制。**

它所提供的功能性救主是：**基因、脑机接口、数字意识和持续增强。**

它所期待的终局是：**自我设计、近乎不死且超越普通人的新物种。**

# 4. Common Grace and Legitimate Concerns

- 反对疾病与不必要痛苦
- 探索医疗修复与辅助技术
- 重视延长健康寿命

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 拒绝受造有限
- 技术精英优越
- 以增强能力重新划分人的价值

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：基因、脑机接口、数字意识和持续增强。
  -> 害怕失去：死亡, 依赖身体, 保持普通人身份
  -> 可能产生：拒绝受造有限, 技术精英优越, 以增强能力重新划分人的价值
```

# 7. Biblical-Theological Lenses

- 创3:22-24 人试图自主掌握永生
- 林前15 身体复活
- 启21 神更新受造界

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

基督教不美化死亡，却盼望身体复活而非抛弃身体；永生是与神相交的礼物，不是精英通过技术购买的升级。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“人类增强”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“身体脆弱、衰老、死亡和生物限制。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “基因、脑机接口、数字意识和持续增强。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：基因、脑机接口、数字意识和持续增强。？
- 你最怕失去什么：死亡、依赖身体，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“基因、脑机接口、数字意识和持续增强。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“拒绝受造有限”？
## 10. 引向基督
- 若基督教不美化死亡，却盼望身体复活而非抛弃身体；永生是与神相交的礼物，不是精英通过技术购买的升级。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 死亡只是工程问题
- 人应摆脱生物身份
- 未增强者会被淘汰

## Counter-evidence
- 保护同等人格尊严
- 区分治疗与等级增强
- 承认死亡与盼望的神学维度

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
