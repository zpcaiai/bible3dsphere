# 1. Purpose

识别、解释并牧养性分析“网红、流量与注意力文化”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 流量等于价值
- 争议可凌驾真实
- 生活全部内容化

## Excludes / Do not overclassify
- 正常内容创作
- 商业传播
- 公共教育

# 3. Fair Definition

把被看见、互动量和可传播性变为存在证明，使人格被压缩为人设，冲突与刺激胜过真理。

它通常把人的根本问题描述为：**无人关注、普通、不可见。**

它所提供的功能性救主是：**算法曝光、粉丝、爆款和持续表演。**

它所期待的终局是：**始终在公共视线中并能把注意力变现。**

# 4. Common Grace and Legitimate Concerns

- 降低表达与创业门槛
- 让专业知识和真实故事传播
- 形成新型社群与创造职业

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 渴求荣耀
- 以粉丝量衡量真理
- 把私生活和他人变成内容资产

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：算法曝光、粉丝、爆款和持续表演。
  -> 害怕失去：掉粉, 过气, 离线后没有价值
  -> 可能产生：渴求荣耀, 以粉丝量衡量真理, 把私生活和他人变成内容资产
```

# 7. Biblical-Theological Lenses

- 太6:1-6 不在人前表演敬虔
- 加1:10 不以讨人喜欢为主
- 约12:43 爱人的荣耀过于神的荣耀

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

人首先活在神的注视中，而非算法凝视中；基督释放人脱离表演性称义，使言语用于真实和造就，而不是不断制造自我。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“网红文化”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“无人关注、普通、不可见。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “算法曝光、粉丝、爆款和持续表演。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：算法曝光、粉丝、爆款和持续表演。？
- 你最怕失去什么：掉粉、过气，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“算法曝光、粉丝、爆款和持续表演。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“渴求荣耀”？
## 10. 引向基督
- 若人首先活在神的注视中，而非算法凝视中；基督释放人脱离表演性称义，使言语用于真实和造就，而不是不断制造自我。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 没人看就没有意义
- 任何关注都是好关注
- 人格必须持续经营

## Counter-evidence
- 保留不可发布生活
- 透明标示商业利益
- 用长期果子而非流量衡量内容

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
