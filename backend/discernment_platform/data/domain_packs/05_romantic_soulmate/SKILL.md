# 1. Purpose

识别、解释并牧养性分析“浪漫主义与灵魂伴侣救恩”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 伴侣必须满足全部需要
- 激情消退即不真实
- 爱情证明人生价值

## Excludes / Do not overclassify
- 健康恋爱期待
- 婚姻亲密
- 离开虐待关系

# 3. Fair Definition

要求伴侣承担终极理解、肯定、医治和完成自我的角色，把强烈感觉等同于真爱。

它通常把人的根本问题描述为：**孤独、不完整、无人完全理解。**

它所提供的功能性救主是：**命定伴侣、激情与无条件情绪满足。**

它所期待的终局是：**由另一个人完成的完整自我。**

# 4. Common Grace and Legitimate Concerns

- 渴望亲密、忠诚与彼此认识
- 肯定婚姻和爱情的珍贵
- 反对纯功利关系

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 要求被完全理解却不愿舍己
- 把伴侣当自我实现工具
- 因感觉消退否定盟约

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：命定伴侣、激情与无条件情绪满足。
  -> 害怕失去：孤独, 平凡婚姻, 被遗弃
  -> 可能产生：要求被完全理解却不愿舍己, 把伴侣当自我实现工具, 因感觉消退否定盟约
```

# 7. Biblical-Theological Lenses

- 弗5:25-32 婚姻指向基督与教会
- 约4 活水胜过关系替代品
- 林前13 爱的忍耐与不求自己益处

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

婚姻是记号而非救主；基督才是终极新郎。人在先被神爱和接纳后，才能不吞噬伴侣，而以盟约、真实和舍己去爱。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“灵魂伴侣”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“孤独、不完整、无人完全理解。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “命定伴侣、激情与无条件情绪满足。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：命定伴侣、激情与无条件情绪满足。？
- 你最怕失去什么：孤独、平凡婚姻，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“命定伴侣、激情与无条件情绪满足。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“要求被完全理解却不愿舍己”？
## 10. 引向基督
- 若婚姻是记号而非救主；基督才是终极新郎。人在先被神爱和接纳后，才能不吞噬伴侣，而以盟约、真实和舍己去爱。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 找到对的人就一切解决
- 真正爱我就该懂我所有情绪
- 没有爱情的人生不完整

## Counter-evidence
- 允许伴侣有限
- 重视盟约和成长
- 能从教会与友谊获得多元支持

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
