# 1. Purpose

识别、解释并牧养性分析“成功神学与繁荣福音”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 奉献保证回报
- 疾病等于信心失败
- 财富证明恩膏

## Excludes / Do not overclassify
- 为需要祷告
- 信靠神供应
- 正当财富管理

# 3. Fair Definition

把十字架福音改写为健康、财富和影响力保证，并把苦难或贫穷归咎于信心不足。

它通常把人的根本问题描述为：**缺乏信心、宣告和属灵原则，导致贫穷疾病。**

它所提供的功能性救主是：**积极宣告、奉献交换和成功型属灵领袖。**

它所期待的终局是：**今生持续富足、健康和上升。**

# 4. Common Grace and Legitimate Concerns

- 相信神关心现实生活
- 鼓励祷告、盼望和慷慨
- 承认财富可用于服侍

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 以成功证明神悦纳
- 轻看受苦者
- 领袖以恩膏逃避问责

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：积极宣告、奉献交换和成功型属灵领袖。
  -> 害怕失去：疾病, 贫穷, 承认祷告未按期待实现
  -> 可能产生：以成功证明神悦纳, 轻看受苦者, 领袖以恩膏逃避问责
```

# 7. Biblical-Theological Lenses

- 可8:34 背十字架跟从
- 腓4:11-13 各样处境知足
- 提前6:3-10 敬虔不是得利门路

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

基督的中心是赦罪、与神和好、十字架与复活；神会供应，也可能呼召人在苦难中忠心，信徒的终极产业在新创造。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“繁荣神学”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“缺乏信心、宣告和属灵原则，导致贫穷疾病。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “积极宣告、奉献交换和成功型属灵领袖。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：积极宣告、奉献交换和成功型属灵领袖。？
- 你最怕失去什么：疾病、贫穷，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“积极宣告、奉献交换和成功型属灵领袖。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“以成功证明神悦纳”？
## 10. 引向基督
- 若基督的中心是赦罪、与神和好、十字架与复活；神会供应，也可能呼召人在苦难中忠心，信徒的终极产业在新创造。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 你不富是因为信心不够
- 种下奉献必得百倍
- 真正蒙福者不会长期受苦

## Counter-evidence
- 允许哀歌和未解苦难
- 财富接受问责
- 福音中心是基督而非成功

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
