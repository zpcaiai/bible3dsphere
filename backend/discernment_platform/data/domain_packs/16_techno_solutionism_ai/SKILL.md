# 1. Purpose

识别、解释并牧养性分析“技术解决主义与AI救世叙事”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- AI会解决人性问题
- 效率就是善
- 治理可完全自动化

## Excludes / Do not overclassify
- 使用AI改善服务
- 工程优化
- 技术研究

# 3. Fair Definition

把人的罪、意义、权力和关系问题简化为信息与优化问题，认为更强系统能自动带来更善社会。

它通常把人的根本问题描述为：**算力不足、信息不全、决策低效。**

它所提供的功能性救主是：**AI、自动化、数据和系统优化。**

它所期待的终局是：**高效、可预测、由智能系统协调的社会。**

# 4. Common Grace and Legitimate Concerns

- 技术能减轻疾病、贫困和信息成本
- AI可增强教育与生产
- 工程方法能解决大量具体问题

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 工程师救世情结
- 能力增长等同道德增长
- 以效率压过尊严与自由

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：AI、自动化、数据和系统优化。
  -> 害怕失去：低效, 不可预测的人, 承认技术制造新问题
  -> 可能产生：工程师救世情结, 能力增长等同道德增长, 以效率压过尊严与自由
```

# 7. Biblical-Theological Lenses

- 创11 巴别塔与技术性集权
- 可7:20-23 恶从人心出来
- 林前8:1 知识叫人自高惟爱造就

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

技术是受造能力的延伸，不是救主；十字架揭示人需要的不只是更聪明，而是被赦免与更新。技术必须服从爱、公义、真理和人的尊严。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“AI救世”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“算力不足、信息不全、决策低效。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “AI、自动化、数据和系统优化。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：AI、自动化、数据和系统优化。？
- 你最怕失去什么：低效、不可预测的人，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“AI、自动化、数据和系统优化。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“工程师救世情结”？
## 10. 引向基督
- 若技术是受造能力的延伸，不是救主；十字架揭示人需要的不只是更聪明，而是被赦免与更新。技术必须服从爱、公义、真理和人的尊严。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 只要模型足够强就不需要伦理
- 人类判断应全部交给算法
- 技术必然使社会更好

## Counter-evidence
- 设置不可自动化边界
- 评估权力与外部性
- 保持人类责任和问责

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
