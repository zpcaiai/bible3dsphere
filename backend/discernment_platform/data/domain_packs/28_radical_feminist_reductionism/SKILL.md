# 1. Purpose

识别、解释并牧养性分析“激进性别权力还原论”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 所有亲密关系本质是压迫
- 男性身份本身构成罪责
- 女性因受压而天然更善

## Excludes / Do not overclassify
- 女性权益
- 反性暴力
- 研究性别不平等

# 3. Fair Definition

把几乎所有男女关系还原为支配结构，并把男性整体视为压迫阶级，使互爱、差异和共同罪性难以被看见。

它通常把人的根本问题描述为：**父权结构渗透语言、家庭与制度。**

它所提供的功能性救主是：**意识觉醒、权力重构、摆脱男性依赖。**

它所期待的终局是：**女性从一切性别性权力关系中解放。**

# 4. Common Grace and Legitimate Concerns

- 揭露性暴力、歧视和制度不公
- 争取女性受教育、工作和公共参与权
- 批评以传统之名合理化压迫

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 群体道德优越
- 受害身份无罪化
- 把和解视为背叛

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：意识觉醒、权力重构、摆脱男性依赖。
  -> 害怕失去：问题被淡化, 重新依赖, 承认女性也能滥权
  -> 可能产生：群体道德优越, 受害身份无罪化, 把和解视为背叛
```

# 7. Biblical-Theological Lenses

- 创1:27 男女同有神形象
- 加3:28 在基督里同等承受救恩
- 可10:42-45 反支配的权柄

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

圣经谴责压迫并肯定男女同有神形象；十字架揭露所有人的罪，也建立非支配、彼此舍己和按恩赐服侍的共同体。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“性别权力还原论”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“父权结构渗透语言、家庭与制度。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “意识觉醒、权力重构、摆脱男性依赖。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：意识觉醒、权力重构、摆脱男性依赖。？
- 你最怕失去什么：问题被淡化、重新依赖，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“意识觉醒、权力重构、摆脱男性依赖。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“群体道德优越”？
## 10. 引向基督
- 若圣经谴责压迫并肯定男女同有神形象；十字架揭露所有人的罪，也建立非支配、彼此舍己和按恩赐服侍的共同体。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 男女不可能真正互信
- 所有传统家庭都是控制
- 只有权力反转才算公义

## Counter-evidence
- 同一标准审查各方
- 允许互惠与和解
- 保护个体不被群体标签吞没

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
