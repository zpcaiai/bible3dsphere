# 1. Purpose

识别、解释并牧养性分析“享乐主义与体验至上”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 快乐是最高标准
- 痛苦必然无意义
- 承诺若不快乐即可抛弃

## Excludes / Do not overclassify
- 健康娱乐
- 旅行和艺术
- 庆典与饮食喜乐

# 3. Fair Definition

把减少痛苦、增加刺激和收集体验变为人生最高目标，使承诺、节制与长期忠信显得不合理。

它通常把人的根本问题描述为：**无聊、痛苦、错过体验。**

它所提供的功能性救主是：**娱乐、旅行、性、食物、游戏和持续新鲜感。**

它所期待的终局是：**体验丰富、痛苦最小且没有遗憾的人生。**

# 4. Common Grace and Legitimate Concerns

- 承认快乐、宴席、旅行和身体享受是礼物
- 反对无必要的禁欲主义
- 鼓励感恩当下

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 认为自己有权持续舒适
- 轻看朴素忠心
- 拒绝承担带来痛苦的责任

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：娱乐、旅行、性、食物、游戏和持续新鲜感。
  -> 害怕失去：无聊, 痛苦, 错过
  -> 可能产生：认为自己有权持续舒适, 轻看朴素忠心, 拒绝承担带来痛苦的责任
```

# 7. Biblical-Theological Lenses

- 传2 对享乐实验的反思
- 提前6:17 神厚赐百物享受
- 来12:2 基督因前面的喜乐忍受十架

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

神赐喜乐却不是让享受承受神的重量；基督赐下能穿越痛苦的喜乐，并训练人以节制、感恩和盼望领受礼物。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“及时行乐”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“无聊、痛苦、错过体验。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “娱乐、旅行、性、食物、游戏和持续新鲜感。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：娱乐、旅行、性、食物、游戏和持续新鲜感。？
- 你最怕失去什么：无聊、痛苦，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“娱乐、旅行、性、食物、游戏和持续新鲜感。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“认为自己有权持续舒适”？
## 10. 引向基督
- 若神赐喜乐却不是让享受承受神的重量；基督赐下能穿越痛苦的喜乐，并训练人以节制、感恩和盼望领受礼物。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 人生只要开心
- 不要让责任妨碍体验
- 痛苦说明走错路

## Counter-evidence
- 能延迟满足
- 在苦难中忠信
- 享受转化为感恩与分享

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
