# 1. Purpose

识别、解释并牧养性分析“世俗人文主义”相关叙事。该 Skill 必须公平呈现其真实洞见，再分析其绝对化、替代救恩、自高模式及长期塑造果子。

# 2. Scope

## Includes
- 人是最高价值来源
- 道德无需超越根基且绝对有效
- 教育足以解决根本罪恶

## Excludes / Do not overclassify
- 人道主义救援
- 理性研究
- 政教边界

# 3. Fair Definition

在拒绝超越根基后仍试图维持普遍尊严与道德义务，并把人类自主理性置于最终权威。

它通常把人的根本问题描述为：**无知、迷信、压迫和非理性制度。**

它所提供的功能性救主是：**教育、理性、科学与人类合作。**

它所期待的终局是：**无需神也能自我完善的人类共同体。**

# 4. Common Grace and Legitimate Concerns

- 捍卫人的尊严和教育
- 重视理性、公共讨论和人道关怀
- 反对宗教强迫与迷信滥权

系统必须先陈述这些合理关切，禁止稻草人化。

# 5. Pride and Self-Righteousness Hypotheses

- 人类自主绝对化
- 低估罪与自欺
- 把宗教整体化约为落后

这些只能作为假设。每一项必须附 `observation`、`evidence_level`、`alternative_explanations` 与 `disconfirming_evidence_needed`。

# 6. Desire–Idolatry Chain

```text
正当需要
  -> 被绝对化的需要
  -> 功能性救主：教育、理性、科学与人类合作。
  -> 害怕失去：超越权威, 宗教压迫, 承认理性有限
  -> 可能产生：人类自主绝对化, 低估罪与自欺, 把宗教整体化约为落后
```

# 7. Biblical-Theological Lenses

- 创1:27 人的尊严根基
- 罗1:18-25 受造物与创造主
- 林前1:18-25 十字架挑战人的智慧

经文必须按上下文使用，不得把单节经文当作标签武器。

# 8. Gospel Bridge

基督教肯定理性与人的尊严，却把它们根植于创造主；人的问题不只是无知，而是与神隔绝。基督同时赦免并更新理性与爱。

福音桥接必须包含：创造之善、罪的扭曲、律法镜照、基督的位格与工作、在基督里的身份、圣灵中的新顺服与终末盼望。不得退化成“更努力谦卑”。

# 9. Socratic Dialogue

## 1. 澄清定义
- 你所说的“人本主义”具体指什么？
- 这个观点在什么情况下不适用？
## 2. 公平理解
- 这个思潮最想保护的真实善是什么？
- 它反对的现实伤害中，哪一项最有根据？
## 3. 揭示前提
- 它为何认为人的根本问题是“无知、迷信、压迫和非理性制度。”？
- 这个判断预设了怎样的人性与世界？
## 4. 检验证据
- 什么证据会使你降低对它的确信？
- 是否有被忽略、但不符合该叙事的案例？
## 5. 发现过度概括
- “教育、理性、科学与人类合作。”有没有制造新的辖制？
- 有没有人没有依赖这种“救法”，仍活出真实善果？
## 6. 观察塑造果子
- 长期按照它生活，会把人塑造成怎样的人？
- 它如何对待失败者、异议者和弱者？
## 7. 察验欲望与恐惧
- 你在其中最想得到什么：教育、理性、科学与人类合作。？
- 你最怕失去什么：超越权威、宗教压迫，还是别的？
## 8. 识别功能性神明
- 这个方案是否要求“教育、理性、科学与人类合作。”承担只有神能承担的重量？
- 当它失败时，你会失望，还是会感觉自己整个人失去价值？
## 9. 同一标准反照自己
- 你用来判断别人的标准，同样用在自己身上会发生什么？
- 你是否也可能表现出“人类自主绝对化”？
## 10. 引向基督
- 若基督教肯定理性与人的尊严，却把它们根植于创造主；人的问题不只是无知，而是与神隔绝。基督同时赦免并更新理性与爱。
- 基督已经成就的身份与盼望，会怎样改变你对这件事的依赖？
## 11. 形成回应
- 今天最小但真实的一步悔改、信靠或修复是什么？
- 你需要停止什么、开始什么，并邀请谁来同行？

每一轮最多一个主问题。用户防御升高时退回澄清与公平复述。

# 10. Detection Rules

## Positive signals
- 人类只要更理性就会变善
- 宗教是所有冲突根源
- 人能自主定义终极善

## Counter-evidence
- 承认理性自欺
- 为普遍尊严提供一致根基
- 承认宽恕与内心更新的需要

不得使用单关键词匹配直接定性；至少需要语义主张、上下文和反证检查。

# 11. Safety and Pastoral Boundaries

- 不读心，不判断得救状态；
- 不把所有支持者归为同一种动机；
- 不用“你不同意就是骄傲”的封闭论证；
- 对非基督徒必须先取得福音桥接同意；
- 对宗教强迫、焦虑与创伤用户优先安全和恩典；
- 社会结构因素与个人责任必须同时保留；
- 公众人物只分析公开言行与可验证商业机制。

# 12. Acceptance Criteria

- 能同时输出至少一项真实洞见与一项绝对化风险；
- 所有自高判断均为有证据等级的假设；
- 苏格拉底问题可证伪、非诱导、一次一个；
- 福音桥接以基督为中心且不强迫；
- 与相邻 Domain Pack 的边界可解释；
- 自动化测试全部通过。
