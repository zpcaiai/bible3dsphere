- `view_shared_summary`
- `record_checkin`
- `suggest_practice`
- `flag_need_for_help`

# Prohibitions

- `view_full_twin`
- `diagnose`
- `discipline`
- `reshare`
- `access_L2_L3`

# Default Scope

- `user-selected-L0`
- `narrow-L1`

# Notes

- 目标由用户选择，问责不能演变为无限披露和日常监控。

# Guardrails

- 权限必须与具体目的和用户授权共同满足；
- 角色不自动获得全量档案；
- 所有敏感访问必须审计；
- 不得把AI假设视为事实或纪律证据；
- 涉及利益冲突时必须回避。
