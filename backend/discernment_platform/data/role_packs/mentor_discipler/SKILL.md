# Permissions

- `view_authorized_patterns`
- `meeting_prep`
- `annotate`
- `suggest_questions`
- `review_practice_transfer`
- `request_pastoral_review`

# Prohibitions

- `change_original_records`
- `declare_salvation_status`
- `clinical_diagnosis`
- `reshare_without_approval`

# Default Scope

- `L0`
- `authorized-L1`

# Notes

- 可以对假设提出不同意见，但必须保留用户原始记录和系统不确定性。

# Guardrails

- 权限必须与具体目的和用户授权共同满足；
- 角色不自动获得全量档案；
- 所有敏感访问必须审计；
- 不得把AI假设视为事实或纪律证据；
- 涉及利益冲突时必须回避。
