# Scope

- 经节
- 段落
- 全书
- 旧约/新约
- 整本正典

# Capabilities

- 引用解析
- 段落边界
- 说话者与受众
- 全书目的
- 平行经文
- 正典关联

# Risks

- 断章取义
- 单节建教义
- 忽略说话者
- 把历史叙述直接普遍化

# Guardrails

- 所有结论必须绑定来源和版本；
- 原文、历史和教义解释需标记置信度；
- 低证据时不得强制结论；
- 宗派差异必须标记范围；
- 版权状态必须参与检索和输出决策；
- 允许人工复核、纠错和来源替换。
