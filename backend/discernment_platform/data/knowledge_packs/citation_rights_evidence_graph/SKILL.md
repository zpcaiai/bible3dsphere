# Scope

- 来源登记
- 版本
- 页码
- 短引
- 许可证
- RAG链路
- 人工复核

# Capabilities

- 引文验证
- 来源质量
- 权利过滤
- 证据边
- 生成陈述追踪
- 审计

# Risks

- 杜撰引文
- 伪造页码
- 版权泄漏
- 二手引文冒充一手
- 无法追踪生成结论

# Guardrails

- 所有结论必须绑定来源和版本；
- 原文、历史和教义解释需标记置信度；
- 低证据时不得强制结论；
- 宗派差异必须标记范围；
- 版权状态必须参与检索和输出决策；
- 允许人工复核、纠错和来源替换。
