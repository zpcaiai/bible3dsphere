# Purpose

针对爆火现象生成从事实核验到心灵察验的自适应单问题路径。

# Trigger

报告形成前或用户进入互动辨识模式时。

# Inputs

叙事、思潮命中、商业模式、受众欲望、用户自身反应。

# Outputs

分阶段问题树、首问、分支条件、安全等级。

# Processing Contract


阶段：
1. Fact：我们实际知道什么？
2. Persona：我们是否把人设当成完整人格？
3. Value：我们在赞美或厌恶什么？
4. Incentive：谁因我们的注意力获益？
5. Audience：它回应了什么真实需要？
6. Fruit：长期会塑造怎样的人？
7. SelfMirror：为什么我特别被它吸引或激怒？
8. Worship：什么有限之物承担了终极重量？
9. Gospel：若基督已经给出身份与荣耀，会改变什么？
10. Practice：应当关注、节制、抵抗还是创造替代？


# Prompt Contract

每轮一个问题；先事实后心灵；不可用问题暗示对方必然有罪。

# Evidence and Uncertainty

每个问题绑定触发它的证据或假设。

# Guardrails

非基督徒进入福音层前必须获得同意；宗教强迫风险时优先恩典和安全。

# Failure Handling

用户防御升高时回到事实澄清。

# Acceptance Tests

问题顺序合理；首问不直接指控偶像；问题可由用户具体回答。
