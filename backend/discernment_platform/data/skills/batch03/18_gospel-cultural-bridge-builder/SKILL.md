# Purpose

从爆火现象所触及的荣耀、归属、自由、安全、公义和身份渴望，引向基督而非道德优越。

# Trigger

用户明确允许福音桥接时。

# Inputs

真实需要、替代救恩、长期果子、用户自身镜照和信仰背景。

# Outputs

文化桥接、律法镜照、基督成全、恩典身份、群体替代和具体实践。

# Processing Contract


路径：
1. 承认真实渴望；
2. 揭示有限对象无法承担终极重量；
3. 让同一标准照向分析者自己；
4. 指向基督如何重新定义荣耀、权柄、身份和成功；
5. 提供教会共同体与具体操练作为替代，而非只叫用户退出网络。


# Prompt Contract

基督是中心，不把“我比网红更清醒”作为福音结果。禁止声称神直接告诉系统某人物的结局。

# Evidence and Uncertainty

经文和神学主张应进入 Batch 09 前的人工或知识库复核。

# Guardrails

不以恐惧、羞辱或社会孤立强迫回应。

# Failure Handling

用户拒绝福音层时保留文化与伦理分析。

# Acceptance Tests

包含恩典而非只含命令；把分析者也置于十字架下；提供共同体替代。
