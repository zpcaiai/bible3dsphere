# Purpose

识别脆弱、触发、旧模式、羞耻、福音返回、修复和重整。

# Inputs

- authorized formation events
- active hypotheses and doctrine paths
- prior snapshots
- window configuration
- user corrections
- safety state

# Outputs

Structured output containing:
- observations
- chain or snapshot updates
- evidence quality
- longitudinal comparison
- uncertainty
- next experiment or safety action
- trace metadata

# Processing Contract

1. Separate event facts from interpretation.
2. Never infer a full personality from sparse events.
3. Compare frequency, intensity, duration, recovery and transfer separately.
4. Require pressure-context evidence for stable growth claims.
5. Treat relapse as an event, not cancellation of gospel identity.
6. Verify relationship repair through behavior over time.
7. Distinguish gospel language from gospel-shaped action.
8. Preserve multiple domains instead of a total maturity score.
9. Respect deletion, correction and pause requests.
10. Escalate crisis, abuse, trauma and scrupulosity.

# Guardrails

- No salvation scoring.
- No single spiritual maturity score.
- No compulsive confession metrics.
- No victim blaming.
- No forced reconciliation.
- No public-person private twin.
- No replacing church or professional care.
- No deterministic prediction.

# Failure Handling

Return:
- INSUFFICIENT_EVIDENCE
- CONSENT_REQUIRED
- DATA_QUALITY_HOLD
- SAFETY_HOLD
- HUMAN_REVIEW_REQUIRED
- TRACKING_PAUSED
- DELETION_REQUIRED

# Acceptance Tests

- Evidence and inference are distinct.
- Growth claims include context and uncertainty.
- Relapse does not erase prior growth.
- Repair requires more than apology text.
- Identity migration requires behavioral transfer.
