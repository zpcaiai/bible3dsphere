# Fair Definition

把神学知识、属灵经历、恩赐、纪律、服侍果效或宗教身份转化为自我荣耀和对他人的属灵等级判断。

# Created Good

- 追求圣洁
- 神学学习
- 祷告
- 服侍
- 属灵恩赐

# Includes

- 启示优越
- 神学优越
- 事工成功称义
- 把不同实践视为低等
- 用属灵语言控制

# Excludes

- 持守教义
- 辨别异端
- 教会纪律
- 成熟带领

# Common Distortions

- 恩赐取代恩典
- 知识取代爱
- 果效成为称义
- 领袖位置成为不可问责

# Observable Signals

- `spiritual_rank_language`：反复以属灵等级评价人（weight=3）
- `revelation_immunity`：以神告诉我阻止检验和问责（weight=4）
- `gift_as_status`：以恩赐或果效证明更蒙神悦纳（weight=3）
- `repentance_deflection`：被指出问题时用事工果效或属灵经历转移（weight=3）

# Alternative Explanations

- 需要清楚教义边界
- 领袖承担真实分辨责任
- 表达传统不同
- 确有成熟与初信差异

# Counter-Evidence

- 恩赐越大越愿受问责
- 能区分真理坚定与自我优越
- 公开悔改
- 重视隐藏忠心胜过平台果效

# Trigger–Response–Fruit Chain

- **trigger**：属灵权威受挑战、事工比较或被忽视
- **interpretation**：如果我不显得更属灵，我就失去价值和权柄
- **desire**：获得神圣认可和不可质疑地位
- **response**：使用属灵等级、启示或果效压制检验
- **short_reward**：权威和崇敬
- **long_cost**：滥权、虚假、群体受伤

# Socratic Questions

- 如果没有人知道你的服侍，你仍愿意做吗？
- 你说“神告诉我”时，是否允许圣经和群体检验？
- 你的知识使你更爱软弱者了吗？
- 十字架中的荣耀与你追求的属灵荣耀有何不同？

# Gospel Bridge

- **law**：恩赐、知识和事工都不能称义；没有爱便算不得什么
- **christ**：基督取奴仆形象，以十字架显明真正荣耀
- **identity**：领袖首先是蒙恩罪人和群羊中的一员
- **practice**：把一个决定交给共同分辨；公开承认一项错误；进行不被看见的服侍
