# Fair Definition

把民族、阶级、政治、性别、专业、学校、公司、教会或宗派身份转化为天然的道德、认知或价值优越。

# Created Good

- 群体归属
- 共同记忆
- 忠诚
- 文化传承
- 团结互助

# Includes

- 本群体天然无罪
- 外群体本质化
- 信息双标
- 以群体成功证明个人价值

# Excludes

- 合理群体认同
- 爱国
- 宗派传统
- 专业共同体

# Common Distortions

- 身份取代真理
- 忠诚高于公义
- 外群体去人格化
- 个人责任被集体荣誉吞没

# Observable Signals

- `ingroup_immunity`：本群体错误被系统性淡化或合理化（weight=3）
- `outgroup_essentialism`：把复杂个体压缩为固定群体本质（weight=3）
- `loyalty_over_truth`：批评本群体被定义为背叛（weight=3）
- `borrowed_glory`：借群体成就建立个人优越（weight=2）

# Alternative Explanations

- 群体正处于真实威胁
- 历史创伤尚未被承认
- 表达是在建立必要团结
- 对方确有系统性错误

# Counter-Evidence

- 能批评本群体
- 能承认外群体的善
- 以同一标准判断各方
- 把个人看作神形象承载者

# Trigger–Response–Fruit Chain

- **trigger**：群体被批评、竞争或身份不安
- **interpretation**：群体若不优越，我也失去价值和安全
- **desire**：获得荣耀、归属和清白
- **response**：双标、去人格化、忠诚测试
- **short_reward**：群体肯定和安全
- **long_cost**：真理受损、敌意加深、悔改受阻

# Socratic Questions

- 你是否允许本群体被同样标准审查？
- 如果对方群体的人做了同样善事，你会承认吗？
- 你的归属是否需要一个较低等的外群体？
- 十字架如何拆毁借群体荣耀称义？

# Gospel Bridge

- **law**：所有群体都在罪下，不能靠历史、文化或阵营称义
- **christ**：基督从各族各方召聚一个以恩典而非优越为根基的群体
- **identity**：归属神家不要求贬低外群体
- **practice**：公开承认本群体一项错误；学习外群体一个真实贡献；停止一种去人格化标签

# Guardrails

- 只输出可证伪假设；
- 单次行为不得推断稳定人格；
- 必须列出替代解释与反证；
- 不得用此 Pack 进行临床诊断、灵魂定罪或宗教羞辱；
- 创伤、文化、职位职责和现实风险必须纳入分析。
