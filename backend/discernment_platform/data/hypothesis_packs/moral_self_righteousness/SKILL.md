# Fair Definition

以自己的正确、受苦、立场或善行证明自己无需同样被审判，并以定罪别人维持正义身份。

# Created Good

- 追求公义
- 辨别善恶
- 保护受害者
- 拒绝妥协

# Includes

- 双重标准
- 定罪快感
- 缺少悔改
- 把对方错误当作自己无罪证据

# Excludes

- 必要问责
- 清楚指出罪恶
- 司法追责
- 保护边界

# Common Distortions

- 公义成为优越感
- 只见对方罪而不见自身
- 用羞辱代替修复
- 认为正确目的可洁净错误手段

# Observable Signals

- `double_standard`：同类行为因阵营不同被不同评价（weight=3）
- `repentance_asymmetry`：只要求对方认错，自己从不承认责任（weight=3）
- `condemnation_reward`：从公开羞辱和定罪中获得身份与群体奖励（weight=2）
- `ends_justify_means`：因目标正确而合理化谎言、夸大或伤害（weight=3）

# Alternative Explanations

- 真实伤害仍未得到承认
- 问责程序尚未完成
- 强烈语言用于保护弱者
- 信息不对称

# Counter-Evidence

- 愿意承认本方错误
- 区分问责与人格毁灭
- 自己也接受同样标准
- 在真理下寻求修复

# Trigger–Response–Fruit Chain

- **trigger**：看到错误、背叛或阵营冲突
- **interpretation**：只要证明对方坏，我就是好的
- **desire**：维持道德纯洁和优越
- **response**：放大对方罪、缩小自身责任
- **short_reward**：正义感和群体肯定
- **long_cost**：悔改能力下降、敌意扩大

# Socratic Questions

- 如果同样行为由你支持的人做出，你会怎样评价？
- 你希望公义恢复，还是希望对方被毁灭？
- 对方的错误是否正在帮你逃避自己的责任？
- 十字架怎样同时维护公义并拆毁自义？

# Gospel Bridge

- **law**：律法把所有人都圈在罪中，不允许靠比较称义
- **christ**：基督担当不义者的审判，也揭露自义者需要恩典
- **identity**：蒙恩罪人不是无原则，而是不靠定罪别人证明自己
- **practice**：用同一标准审查本方；在问责中删除羞辱性措辞；具体承认自己的一项责任

# Guardrails

- 只输出可证伪假设；
- 单次行为不得推断稳定人格；
- 必须列出替代解释与反证；
- 不得用此 Pack 进行临床诊断、灵魂定罪或宗教羞辱；
- 创伤、文化、职位职责和现实风险必须纳入分析。
