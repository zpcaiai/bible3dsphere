# Fair Definition

把真实受伤或受压迫经历转化为当前一切判断和行为的无条件正当性，从而取消持续的道德责任。

# Created Good

- 承认创伤
- 保护受害者
- 倾听弱者
- 追求公义和赔偿

# Includes

- 受伤即永远正确
- 以创伤合理化伤害
- 拒绝任何自省
- 身份永久冻结在受害位置

# Excludes

- 创伤反应
- 必要保护和愤怒
- 追责
- 暂时无法和解

# Common Distortions

- 伤害成为道德豁免
- 同理心取代真理
- 责任被视为二次伤害
- 永远需要敌人维持身份

# Observable Signals

- `harm_as_immunity`：以曾受伤为当前所有行为免责（weight=3）
- `feedback_rejection`：任何责任提醒都被解释为否认伤害（weight=3）
- `permanent_enemy_need`：身份需要持续存在的压迫者或敌人（weight=2）
- `retaliation_justified`：把报复、羞辱或控制视为当然补偿（weight=3）

# Alternative Explanations

- 伤害仍在发生
- 缺乏安全和法律支持
- 责任提醒方式带有责备受害者倾向
- 创伤记忆尚未整合

# Counter-Evidence

- 既坚持追责也承认自己的选择
- 能区分解释与正当化
- 接受安全环境中的反馈
- 逐渐建立不依赖敌人的身份

# Trigger–Response–Fruit Chain

- **trigger**：被提醒责任、遇到相似情境或权力不平等
- **interpretation**：如果我承认责任，就等于否认自己受过伤
- **desire**：保住清白和保护
- **response**：拒绝反馈、合理化反击
- **short_reward**：免于羞耻和无力感
- **long_cost**：关系修复受阻、身份被伤害锁定

# Socratic Questions

- 承认你的一项责任，是否必然否认别人对你的伤害？
- 你的反应是在保护边界，还是在复制伤害？
- 如果敌人不再存在，你会如何描述自己？
- 基督怎样既不淡化伤害，又不让伤害成为你的最终身份？

# Gospel Bridge

- **law**：受伤者仍是有尊严和责任的行动者；伤害不能洁净人的所有行为
- **christ**：基督看见受苦者，也担当受苦者和加害者都需要面对的罪
- **identity**：身份不必永久被伤害定义，而可在基督里成为被爱、被医治、能重新行动的人
- **practice**：把解释与正当化分开书写；在安全关系中承认一项自己的选择；寻求创伤知情的牧养或专业支持

# Guardrails

- 只输出可证伪假设；
- 单次行为不得推断稳定人格；
- 必须列出替代解释与反证；
- 不得用此 Pack 进行临床诊断、灵魂定罪或宗教羞辱；
- 创伤、文化、职位职责和现实风险必须纳入分析。
