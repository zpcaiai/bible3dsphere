# Fair Definition

把知识、理性、洞察或信息优势转化为自我价值和对他人的轻视，并逐渐失去被事实、群体智慧和神纠正的能力。

# Created Good

- 追求真理
- 理性分析
- 专业判断
- 识别错误
- 勇于持守事实

# Includes

- 选择性怀疑
- 不可证伪的自信
- 轻视普通人
- 把知识当身份
- 对反证提高门槛

# Excludes

- 有证据的专业结论
- 面对错误仍坚持事实
- 合理怀疑
- 清晰表达不同意见

# Common Distortions

- 把知道更多等同于更有价值
- 只要求对方证明而不要求自己
- 把不同意见解释为愚蠢或邪恶
- 无法说不知道

# Observable Signals

- `certainty_without_falsifier`：高确定性表达，但不能说明什么证据会改变看法（weight=3）
- `asymmetric_skepticism`：对对方证据极端怀疑，对本方证据极度宽松（weight=3）
- `contempt_language`：反复使用愚蠢、低认知、没脑子等身份贬低（weight=2）
- `correction_resistance`：被纠正时转移标准、羞辱纠正者或修改原主张（weight=3）

# Alternative Explanations

- 时间压力下表达过度简化
- 特定领域确有专业优势
- 对方长期恶意争论导致防御
- 文化中的强语气习惯

# Counter-Evidence

- 能够公开承认错误
- 主动寻找最强反例
- 对同阵营使用同样证据标准
- 能区分不知道与不同意

# Trigger–Response–Fruit Chain

- **trigger**：被质疑、遇到陌生领域或权威受挑战
- **interpretation**：如果我错了，我的价值和地位会下降
- **desire**：保持优越和确定感
- **response**：提高语气、贬低对方、拒绝反证
- **short_reward**：恢复掌控和优越感
- **long_cost**：学习停滞、关系破裂、真理工具化

# Socratic Questions

- 什么证据会使你改变看法？
- 你是否对自己阵营使用同样标准？
- 如果你在这件事上错了，你最怕失去什么？
- 知道得更清楚是否正在使你更爱人？

# Gospel Bridge

- **law**：知识不能使人自我称义；知道真理却不爱人仍显出亏缺
- **christ**：基督是真理，却以谦卑和舍己临到无知的人
- **identity**：价值不由认知排名决定，而由在基督里被认识和接纳
- **practice**：每日记录一个不知道；主动陈述最强反方；公开纠正一次自己的错误

# Guardrails

- 只输出可证伪假设；
- 单次行为不得推断稳定人格；
- 必须列出替代解释与反证；
- 不得用此 Pack 进行临床诊断、灵魂定罪或宗教羞辱；
- 创伤、文化、职位职责和现实风险必须纳入分析。
