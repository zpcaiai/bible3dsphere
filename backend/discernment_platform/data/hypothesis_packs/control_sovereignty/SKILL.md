# Fair Definition

把计划、责任、秩序和风险管理绝对化，仿佛只有自己掌控才能安全，逐渐无法容纳他人自由、未知和神的护理。

# Created Good

- 计划
- 谨慎
- 责任
- 风险管理
- 保护弱者

# Includes

- 不能委派
- 对未知过度焦虑
- 把建议变成命令
- 控制关系
- 不能接受不同路径

# Excludes

- 必要监督
- 危机指挥
- 清楚边界
- 合规与安全控制

# Common Distortions

- 把控制等同于爱
- 把不确定等同于灾难
- 把他人变成项目
- 把神的护理变成理论而非信靠

# Observable Signals

- `uncertainty_intolerance`：对合理未知出现不成比例的焦虑和控制（weight=3）
- `people_as_projects`：持续替他人决定并管理其成长（weight=3）
- `delegation_with_micromanagement`：表面委派但保留全部细节控制（weight=2）
- `outcome_ownership`：把所有结果都视为自己必须保证（weight=3）

# Alternative Explanations

- 现实环境高风险
- 他人曾严重失信
- 职责边界确实要求监督
- 焦虑或创伤反应

# Counter-Evidence

- 能区分责任与结果主权
- 允许他人承担后果
- 对未知保持行动与安息
- 委派后不持续夺回

# Trigger–Response–Fruit Chain

- **trigger**：不确定、他人犯错、进度偏离或关系失控
- **interpretation**：如果我不控制，一切会崩溃
- **desire**：获得安全和确定
- **response**：微管理、替代决定、扩大责任
- **short_reward**：短暂安全感
- **long_cost**：焦虑加重、他人失能、关系窒息

# Socratic Questions

- 这是你的责任，还是你试图拥有的结果主权？
- 你控制的是风险，还是别人的自由？
- 如果事情不按你的方式发展，你最怕这说明什么？
- 基督掌权若是真的，你可以放下哪一项不属于你的责任？

# Gospel Bridge

- **law**：人不能成为全知全能的护理者
- **christ**：基督掌权，使人可以忠心而不必扮演主权者
- **identity**：我是管家，不是世界的维持者
- **practice**：列出责任圈与主权圈；委派并允许可承受错误；每天为一个无法控制的事项祷告后停止重复检查

# Guardrails

- 只输出可证伪假设；
- 单次行为不得推断稳定人格；
- 必须列出替代解释与反证；
