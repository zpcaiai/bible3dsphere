# Core Claims

- 耶稣基督是真神也是真人，是唯一中保。
- 祂完全顺服，担当罪与咒诅，在十字架上为罪人舍己。
- 祂身体复活、升天并现今掌权。
- 十字架同时显明代替、赎价、得胜、和好、献祭和新约等丰富维度。

# Human Problems Addressed

- 罪责
- 羞耻
- 奴役
- 与神隔绝
- 死亡
- 邪恶权势

# Role in Gospel Path

从人的失败转向基督客观完成的救赎事实。

# Depends On

- `uses_of_law`

# Common Distortions

- 只把耶稣当榜样
- 只谈爱不谈罪与公义
- 只谈刑罚不谈复活与得胜
- 把某一代赎模型排他绝对化

# Pastoral Applications

- 把注意力从自我分析转向基督
- 将罪责、羞耻、奴役和死亡分别连接到基督工作

# Socratic Entries

- **christ**：如果救恩取决于基督已经完成的工作，而不是你的表现，会改变什么？
- **atonement**：你现在最需要面对的是罪责、羞耻、辖制，还是与神隔绝？

# Denominational Notes

- [TIER_2] 传统对不同代赎模型的强调不同，但不应否定基督代替性舍己与复活得胜。
