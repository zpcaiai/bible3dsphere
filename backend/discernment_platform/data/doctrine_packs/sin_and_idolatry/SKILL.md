# Core Claims

- 罪既是违背神的行为，也是心对神的不信、悖逆和扭曲敬拜。
- 偶像化是要求受造物承担身份、救恩、安全、荣耀或终极意义。
- 罪影响个人、关系、制度和受造界，不能只化约为个人坏习惯。
- 所有人都在罪下，不能靠比较、受害身份、知识、能力或宗教表现称义。

# Human Problems Addressed

- 自我称义
- 功能性救主
- 结构性罪遗漏
- 只改行为不改敬拜

# Role in Gospel Path

把具体问题连接到更深的敬拜、信靠和自我称义结构。

# Common Distortions

- 把所有痛苦归因于个人罪
- 把偶像分析变成猜测内心
- 只谈个人不谈结构
- 只谈结构取消个人责任

# Pastoral Applications

- 区分正当需要与绝对化欲望
- 识别功能性救主
- 同时保留受苦与责任
