# Core Claims

- 独一三一神自由、智慧且良善地创造万有。
- 人按神形象受造，具有不可由成就、群体或消费价值取消的尊严。
- 身体、关系、工作、权柄、自由和受造界都具有来自神的意义与界限。
- 受造物是礼物和托付，不是终极神明。

# Human Problems Addressed

- 身份无根
- 自我创造压力
- 身体与关系工具化
- 能力和地位称义

# Role in Gospel Path

建立福音诊断的正面起点：先说明神原本的善，再说明罪如何扭曲。

# Depends On

- None

# Common Distortions

- 把创造秩序变成文化习惯绝对化
- 否定受造界的多样性
- 把自然状态直接等同道德规范
- 把创造论只缩减为科学起源争论

# Pastoral Applications

- 肯定真实欲望中的受造之善
- 恢复身体与工作的管家观
- 将身份从自我发明转向被造与被认识

# Socratic Entries

- **created_good**：你所追求的东西里面，有什么原本是好的？
- **identity**：如果价值不是由表现决定，人为何仍有尊严？
