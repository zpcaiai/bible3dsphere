# Core Claims

- 基督召聚一个有形、真实、彼此委身的群体。
- 圣道、洗礼、圣餐、祷告、敬拜、纪律、服侍和彼此相爱是门徒生命的重要环境。
- 教会领袖必须受圣经、群体和问责约束。
- 教会错误不能取消基督和教会作为祂身体的真理，但伤害必须被认真处理。

# Human Problems Addressed

- 孤立式信仰
- 网红替代教会
- 属灵消费主义
- 缺少问责
- 教会创伤

# Role in Gospel Path

把个人福音回应连接到基督身体、恩典媒介、服侍和相互问责。

# Depends On

# Common Distortions

- 把教会等同某个领袖
- 把顺服变成无条件服从
- 否定受伤者边界
- 把线上内容等同完整教会生活

# Pastoral Applications

- 寻找健康教会
- 建立导师与同伴
- 处理伤害、纪律和修复
- 参与圣礼和服侍
