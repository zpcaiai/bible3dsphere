# Core Claims

- 基督将再来，死人将复活，神将施行公义审判。
- 神的终局包括新天新地、受造界更新、罪与死亡终结以及神与人同住。
- 基督徒盼望既使人忍耐苦难，也推动今世忠心、公义与爱。
- 终末盼望不等于逃避身体、历史、工作或公共责任。

# Human Problems Addressed

- 死亡恐惧
- 苦难无意义
- 政治乌托邦
- 即时成功压力
- 绝望与虚无

# Role in Gospel Path

把当前失败、受苦、未完成和公义渴望置于复活与新创造中。

# Depends On

- `christ_and_atonement`

# Common Distortions

- 灵魂逃离世界
- 计算末日时间
- 用未来否定当前责任
- 把某政治项目等同神国完成

# Pastoral Applications

- 在失败中保持忠心
- 面对死亡与哀伤
- 拒绝乌托邦和绝望
- 将身体与工作放进新创造盼望

# Socratic Entries

- **hope**：如果最终结果不由你现在的成功决定，你今天可以怎样忠心？
- **resurrection**：身体复活和新创造怎样改变你对当前痛苦的理解？

# Denominational Notes

- [TIER_2] 千禧年、灾难和被提次序属于传统内差异，不应取代复活与再来的核心。
