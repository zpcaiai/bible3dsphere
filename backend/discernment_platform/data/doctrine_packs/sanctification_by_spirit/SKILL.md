# Core Claims

- 圣灵使人重生、内住、更新心意并结出基督生命的果子。
- 成圣是神恩典的工作，也包含信徒真实、主动、依赖圣灵的顺服。
- 治死罪与活出新生命都在联合基督中进行。
- 成长通常是渐进、群体性并经历争战，不应以瞬间完美作为正常标准。

# Human Problems Addressed

- 行为主义
- 消极主义
- 完美主义
- 反复失败
- 属灵表演

# Role in Gospel Path

把福音身份转化为圣灵中的真实生命更新。

# Depends On

- `union_with_christ`

# Common Distortions

- 靠意志自救
- 以一次经历代替长期成圣
- 用恩典否定操练
- 以操练证明称义

# Pastoral Applications

- 设计恩典驱动的操练
- 区分跌倒与身份取消
- 连接圣灵、圣道、祷告和群体

# Socratic Entries

- **sanctification**：这个行动是在赚取接纳，还是在回应已经领受的恩典？
- **spirit**：你准备怎样依靠圣灵，而不是只靠意志压制自己？
