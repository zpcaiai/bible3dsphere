# Core Claims

- 称义是神因基督宣告罪人为义的恩典行动。
- 称义的根据是基督的义与工作，不是人的善行、属灵表现或心理状态。
- 信心是领受基督的器皿，不是可夸的功德。
- 真信心不孤立，却必须与成圣果子区分。

# Human Problems Addressed

- 能力称义
- 道德自义
- 宗教表现焦虑
- 失败身份崩塌

# Role in Gospel Path

拆毁一切自我称义，把接纳根据放在基督之外在工作上。

# Depends On

- `christ_and_atonement`

# Common Distortions

- 把信心变成新功德
- 用行为果子倒推每天是否被称义
- 把称义理解为神假装看不见罪
- 用称义取消悔改和成圣

# Pastoral Applications

- 帮助失败者区分身份与表现
- 停止靠反复认罪赚取赦免
- 使悔改成为回应而非交易

# Socratic Entries

- **justification**：你现在依靠什么证明自己配被接纳？
- **faith**：信心若只是空手领受，你还有什么可以自夸？
