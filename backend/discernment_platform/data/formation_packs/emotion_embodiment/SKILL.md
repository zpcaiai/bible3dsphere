# Focus

- 情绪命名
- 身体预警
- 暂停能力
- 共同调节
- 恢复时间

# Healthy Fruits

- 更早识别身体信号
- 减少冲动持续时间
- 能寻求支持
- 不把情绪等同真理

# Warning Signals

- 情绪压抑被当作成熟
- 平静只因回避冲突
- 身体症状被属灵化

# Evidence

- 身体信号记录
- 恢复时间
- 冲突中的调节
- 专业支持使用

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
