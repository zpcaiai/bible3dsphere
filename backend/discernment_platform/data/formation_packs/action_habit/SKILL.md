# Focus

- 选择
- 回避
- 节制
- 操练
- 环境设计
- 重复行为

# Healthy Fruits

- 新行动在多个场景出现
- 失败后能恢复
- 操练服务于爱而非自义

# Warning Signals

- 连续打卡但关系无果子
- 操练成为荣耀交换
- 只在低压环境成功

# Evidence

- 行为事件
- 压力场景迁移
- 中断后的恢复
- 导师观察

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
