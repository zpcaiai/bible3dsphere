# Focus

- 正当需要
- 绝对化欲望
- 功能性救主
- 恐惧
- 隐性荣耀

# Healthy Fruits

- 能命名真正想要什么
- 愿意失去部分控制或荣耀
- 受造物回到礼物位置

# Warning Signals

- 把压抑欲望当成成圣
- 只改变外在目标
- 新偶像替代旧偶像

# Evidence

- 选择代价
- 资源分配
- 失去后的反应
- 祷告与行动一致性

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
