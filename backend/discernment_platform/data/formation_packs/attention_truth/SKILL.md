# Focus

- 注意力分配
- 事实与解释区分
- 证据习惯
- 纠错能力
- 媒体与网红影响

# Healthy Fruits

- 能暂停再判断
- 主动查证
- 承认不知道
- 减少情绪驱动转发

# Warning Signals

- 只在安静环境中能分辨
- 压力下重新采用双标
- 以熟悉叙事替代证据

# Evidence

- 信息消费日志
- 纠错记录
- 冲突场景回答
- 转发行为

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
