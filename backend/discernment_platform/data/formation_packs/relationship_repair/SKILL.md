# Focus

- 倾听
- 边界
- 责任
- 道歉
- 补偿
- 信任恢复
- 非报复

# Healthy Fruits

- 准确承担责任
- 停止伤害行为
- 尊重边界
- 接受信任恢复需要时间

# Warning Signals

- 道歉只为结束冲突
- 属灵语言替代补偿
- 要求受伤者立即饶恕或接触

# Evidence

- 对方反馈
- 后续行为
- 第三方问责
- 重复压力场景

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
