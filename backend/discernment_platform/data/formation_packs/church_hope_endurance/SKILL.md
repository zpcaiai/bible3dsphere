# Focus

- 现实教会连接
- 圣道圣礼
- 彼此问责
- 苦难忍耐
- 终末盼望
- 公共忠心

# Healthy Fruits

- 不以AI或网红替代教会
- 在苦难中仍有盼望
- 接受群体纠正
- 不以即时成功判断神同在

# Warning Signals

- 属灵孤立
- 末世计算替代忠心
- 教会伤害被否认
- 盼望被简化为逃避现实

# Evidence

- 教会参与
- 导师关系
- 苦难中的选择
- 公共与家庭忠心

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
