# Focus

- 称义根据
- 儿女身份
- 联合基督
- 羞耻恢复
- 失败后的福音回归

# Healthy Fruits

- 失败不再导致身份崩塌
- 更快回到基督客观工作
- 不靠表现维持接纳
- 能接受帮助和纠正

# Warning Signals

- 只会复述身份口号
- 每次失败都重新检查得救
- 行为改善成为接纳根据

# Evidence

- 压力下的解释变化
- 失败后的恢复路径
- 他人反馈
- 跨场景行动变化

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
