# Focus

- 能力托付
- 委派
- 安息
- 责任边界
- 金钱与成功
- 服侍

# Healthy Fruits

- 工作不再承担身份重量
- 能委派
- 尊重普通能力者
- 能休息和接受限制

# Warning Signals

- 效率提高但控制更强
- 服侍增加但家庭受损
- 工作表现继续决定自我价值

# Evidence

- 委派事件
- 工作冲突
- 安息实践
- 同事与家庭反馈

# Guardrails

- 不用单一分数代表本领域成熟度；
- 不把过程指标自动当作生命果子；
- 必须包含压力情境与关系证据；
- 允许成长、停滞、复发和恢复并存；
- 不以本领域结果判断称义或得救状态。
